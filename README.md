# Brandon-s-projects

Greeting to whom it may concerns,

This project focuses on analyzing how oil price movements affect the S&P 500 and how the broader market reacts to those changes. It is delivered as a Jupyter Notebook, allowing you to run the analysis step‑by‑step and view all charts, calculations, and results interactively. To use it, open the .ipynb file in Jupyter Notebook or JupyterLab, run each cell in order, and the notebook will automatically load the datasets, compute volatility metrics, generate visualizations, and execute the machine‑learning and email‑alert components. Before running the alert system, make sure to enter your own email address and app password in the designated section of the notebook, as this is required for sending notifications. All outputs appear directly inside the notebook, making it easy to explore the full impact of oil price movements on the S&P 500 and related market indicators.
